# Security policy

## Supported versions

Mouvadah is alpha software. Security fixes are applied to the latest `0.1.x`
release; older patch releases may not receive fixes.

## Report a vulnerability privately

Do not open a public issue for a suspected vulnerability or include secrets,
credentials, personal data, or exploit details in public discussion.

Use
[GitHub private vulnerability reporting](https://github.com/andrewb1234/mouvadah/security/advisories/new)
to send a confidential report. Include the affected version, impact, minimal
reproduction steps, and any suggested mitigation. Remove real credentials and
personal data from logs or examples.

Reports are acknowledged and triaged on a best-effort basis. Mouvadah does not
currently offer a response-time SLA or bug-bounty program.

## Scope

The repository, published Mouvadah Community artifacts, and the hosted alpha at
`mouvadah.com` are in scope. Third-party services and social-engineering attacks
are out of scope.
